# Opencode proxy

[**Opencode proxy**](https://github.com/jasonxu114514/opencode2api) - это проект для обхода блокировок opencode.ai в использовании бесплатных облачных моделей из прочих клиентов.

## Создание контейнера

Все переменные перечислены в файле [.env.tmpl](compose/.env.tmpl)

### Значимые переменные среды **Opencode proxy**

Порты:

- `OPPROXY_HTTP_PORT` - порт для связи с приложением по HTTP протоколу.
- `OPPROXY_API_PORT`  - порт для API взаимодействия.

### Запуск и начальные настройки

При первом запуске в томе opencode-proxy-data будет сгенерирован файл настроек *config.json*. После этого необходимо:

- Остановить контейнер
- Открыть файл *config.json* через текстовый редактор и задать следующие настройки
  - `"anonymous": true`
  - `"server_keys": ["Сгенерировать ключ"]`
  - `"webui": { ... "password": "Сгенерировать пароль" ... }`
- Запустить контейнер снова
